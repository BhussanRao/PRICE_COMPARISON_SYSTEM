# 🛒 Price Comparison System

A web-based **Price Comparison System** that helps users search for products and compare prices across multiple e-commerce platforms such as **Amazon and Flipkart**. The project provides a centralized interface where users can quickly evaluate prices and find better deals.

---

## 📌 About The Project

Online shoppers often need to visit multiple e-commerce websites to compare the price of the same product. This process can be time-consuming and inconvenient.

The **Price Comparison System** solves this problem by bringing product information and pricing data together in one place. Users can search for a product and compare its available prices across different platforms, helping them make faster and smarter purchasing decisions.

---

## ✨ Features

* 🔍 Search for products easily
* 💰 Compare prices from multiple e-commerce platforms
* 🛍️ View product names, prices, and details
* 🔗 Direct links to product pages
* 📊 Organized price comparison
* ⚡ Fast and simple user interface

## 🚀 Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/price-comparison-system.git
```

### 2. Navigate to the Project

```bash
cd price-comparison-system
```

### 3. Create a Virtual Environment

```bash
python -m venv venv
```

### 4. Activate the Environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

### 5. Install Dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the Application

```bash
python app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000/
```
